# Shadow authority replay policy (read-only security specification)

Read `/app/fedproto/WORKSPACE_LAYOUT.md` first for module name, directory layout, and build commands.

This document defines the authorization-policy and privilege-escalation rules for the offline IAM security auditor. Implement these rules in Go under `/app/svc` and `/app/pkg` only; do not edit this file or other files under `/app/fedproto/`.

Fixtures live under `/app/trustcorpus` as `realmcase_XX.json` (01–62) plus `/app/trustcorpus/realmcase_XX/federation_trace.ajn` (AJN1 little-endian per `AJN1_WIRE_FORMAT.md`). JSON files hold scenario defaults only (no `events` array). `/app/trustcorpus/trust_index.json` lists `scenarios` in processing order.

## Scenario defaults

- `require_checkpoint_on_internal` (bool, default true when the field is omitted from JSON)
- `block_partner_to_privileged` (bool, default true when omitted)
- `policy_overrides` (optional object)

Apply `policy_overrides` on top of defaults before replay. **Recognized override keys** are exactly:

`require_checkpoint_on_internal`, `block_partner_to_privileged`, `require_checkpoint_prefixes`, `reset_trust_domain_on_revoke`, `attenuate_on_allow`, `open_authority_lex_first`, `suppress_lateral_movement`, `audit_partner_privileged_asymmetry`

Misspelled or differently cased keys (for example `block_partner_to_Privileged`, `open_authority_lex_First`, `audit_partner_privileged_Asymmetry`) are **inert**. Boolean overrides apply only when the JSON value is a boolean `true` or `false`; strings such as `"false"` / `"true"`, numbers, and `null` leave the prior boolean unchanged. `require_checkpoint_prefixes` applies only when its JSON value is an array of strings; a string or other type leaves the prefix list empty. When prefixes are active, ignore empty-string prefix entries. Any `AUTHORITY_ACTION` whose `action` string has a prefix equal to one of the remaining listed strings (byte-wise prefix match, case-sensitive) must satisfy `has_checkpoint` even when the target tier is not `internal` or `require_checkpoint_on_internal` is false.

- `reset_trust_domain_on_revoke` defaults to **false**
- `attenuate_on_allow` defaults to **false**. When true, a successful `ALLOW_FEDERATION` strips child scopes not held by the parent (see ALLOW); **pinned** scopes are never stripped
- `open_authority_lex_first` defaults to **false**. When true, `OPEN_AUTHORITY_PATH` `detail` is the lexicographically **first** inbound partner (not the last). When false (default), use lexicographically **last** partner
- `suppress_lateral_movement` defaults to **false**. When true, never emit `LATERAL_MOVEMENT` (`PRIVILEGE_ESCALATION` may still fire)
- `audit_partner_privileged_asymmetry` defaults to **false**. When true, `FEDERATION_ASYMMETRY` also covers live partner→privileged edges lacking a reciprocal privileged→partner edge (same entity/detail shape as partner→internal). When false (default), partner→privileged edges are outside the asymmetry rule

## Event kinds (journal payloads)

Every replayed scenario uses exactly these event kinds. Implement **all** of them in authority replay:

| Kind | Purpose |
|------|---------|
| `REGISTER_REALM` | Create realm tier state (or resurrect tombstone) |
| `PURGE_REALM` | Tombstone a realm and purge touching edges/scopes |
| `ALLOW_FEDERATION` | Add directed federation edge |
| `REVOKE_FEDERATION` | Remove directed federation edge when present |
| `BIND_SCOPE` | Add scope to realm bound scopes (optional federation provenance, expiry, pin) |
| `SUSPEND_REALM` | Mark suspended (blocks AUTHORITY / ALLOW / BIND) |
| `QUARANTINE_REALM` | Mark quarantined (blocks ALLOW / BIND, **not** AUTHORITY) |
| `FREEZE_REALM` | Mark frozen (blocks BIND / AUTHORITY, **not** ALLOW) |
| `SEAL_REALM` | Mark sealed (blocks AUTHORITY only; never ALLOW or BIND) |
| `UNSEAL_REALM` | Clear sealed flag only (does not clear suspend/quarantine/freeze) |
| `ROTATE_TRUST_DOMAIN` | Overwrite registered **and** effective domain together |
| `AUTHORITY_ACTION` | Cross-realm authority call with policy checks |

Journal payloads may include a `realm_id` field. That field is **not** always the sort key:

| Kind | Sort-key `realm_id` value |
|------|---------------------------|
| `ALLOW_FEDERATION`, `REVOKE_FEDERATION` | `to_realm` |
| `AUTHORITY_ACTION` | `target_realm` |
| All other kinds | payload `realm_id` |

For federation and authority events, the payload may also include a `realm_id` field; the sort key still comes from the table above.

## Event ordering and deduplication

After AJN1 decode (`AJN1_WIRE_FORMAT.md`), sort valid events ascending by `(seq, realm_id, event_id)` using the sort-key table above. Then walk in that order: for each event whose `event_id` is a **non-empty** string (including whitespace-only strings such as `" "`), the first row with that exact `event_id` is replayed and later rows with the same `event_id` are skipped. Do **not** trim `event_id` before comparison. Events with missing or empty `event_id` (`""`) never enter the duplicate map and are always replayed. Count skipped rows in `duplicate_events_skipped`.

**Expiry sweep:** immediately before applying each replay event (after duplicate `event_id` skip), drop every **unpinned** live scope whose `expires_at_seq` is set and satisfies `expires_at_seq <= current_event.seq`. **Pinned scopes are never expired.** An `AUTHORITY_ACTION` at `seq == expires_at_seq` must already see unpinned expired scopes as gone.

**`max_seq` for post-replay audits:** take the maximum `seq` among **all decoded valid events**, including rows later skipped for duplicate `event_id`. When there are no events, `max_seq` is `0` so audit `event_seq` is `1`. Duplicate skips must still advance this maximum.

## Realm state

Per live `realm_id`: `tier` (`internal`, `partner`, or `privileged`), `registered_domain` (immutable string captured at successful `REGISTER_REALM`, overwritten only by `ROTATE_TRUST_DOMAIN`), `trust_domain` / effective domain (string, mutated by federation inheritance and rotate), `bound_scopes` (set of strings from `BIND_SCOPE`), `suspended` (bool, default false), `quarantined` (bool, default false), `frozen` (bool, default false), `sealed` (bool, default false), internal provenance map from each bound scope to the `via_edge` grantor realm id (empty string when bound without `via_edge`), per-scope `expires_at_seq` (omit/`0` = never), per-scope `active_after_seq` (omit/`0` = immediately active), and per-scope `pinned` flag (default false).

Track purged realm IDs in a per-scenario **tombstone** set. Tombstoned IDs are absent from live realm state and from the snapshot `realms` array until the scenario ends (re-register does not clear the tombstone).

**Active scopes for privilege checks:** a bound scope counts toward `AUTHORITY_ACTION` propagated-scope checks only when it is not expired and either `active_after_seq` is unset/`0` or `current_event.seq > active_after_seq` (**strict** greater-than). At `seq == active_after_seq` the scope is still inactive. **Pinned does not bypass `active_after_seq`.** Snapshot `bound_scopes` still lists inactive-but-bound scopes.

## REGISTER_REALM

Fields: `realm_id`, `tier`, optional `trust_domain` (default **`mesh-core`** when omitted or empty).

If `realm_id` is in the tombstone set → `RESURRECTED_REALM` (`entity_id` = `realm_id`, `detail` = **empty**; **no mutation**).

Else if `realm_id` already exists in live state → `DUPLICATE_REALM` (no mutation).

Else create realm with empty bound scopes, `suspended`/`quarantined`/`frozen`/`sealed` = false, and both `registered_domain` and effective `trust_domain` = provided value or `mesh-core`. Do **not** trim whitespace: a value such as `"mesh-core "` (trailing space) is distinct from `"mesh-core"` and must participate in domain equality and lexicographic min checks as-is.

## PURGE_REALM

Fields: `realm_id`.

Missing live realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind).

Else:
1. Delete every live federation edge where `from_realm` or `to_realm` equals `realm_id`.
2. For every **remaining** live realm, delete every **unpinned** bound scope whose provenance grantor equals `realm_id`. **Pinned scopes are not removed by via_edge cascade.** Direct binds (empty `via_edge`) on neighbors stay.
3. Remove `realm_id` from live realm state and add it to the tombstone set.

Pins do **not** survive host purge: when the realm that holds the binding is itself purged, the whole realm (including pinned scopes) is removed.

## ALLOW_FEDERATION

Fields: `from_realm`, `to_realm` (both non-empty).

If `from_realm == to_realm` → **silent no-op**: emit **no** finding and **do not** add an edge (self-federation is never recorded).

If either endpoint is unknown → `UNKNOWN_ACTOR` when `from_realm` is missing (`entity_id` = `from_realm`, `detail` = event kind); else `UNKNOWN_TARGET` (`entity_id` = `to_realm`, `detail` = event kind).

Else if `from_realm` is suspended → `SUSPENDED_REALM` (`entity_id` = `from_realm`, `detail` = `from`) and **do not** add the edge.

Else if `to_realm` is suspended → `SUSPENDED_REALM` (`entity_id` = `to_realm`, `detail` = `to`) and **do not** add the edge.

Else if `from_realm` is quarantined → `QUARANTINED_REALM` (`entity_id` = `from_realm`, `detail` = `from`) and **do not** add the edge.

Else if `to_realm` is quarantined → `QUARANTINED_REALM` (`entity_id` = `to_realm`, `detail` = `to`) and **do not** add the edge.

Sealed endpoints do **not** block ALLOW.

Else if directed edge `from_realm→to_realm` already exists → `DUPLICATE_FEDERATION` (`entity_id` = `to_realm`, `detail` = `from_realm`). Else record the edge, then apply **last-allow domain pinning**: set effective `trust_domain` of `to_realm` to `min(from_realm.effective, to_realm.registered_domain)` and mark `to_realm` domain-pinned. **Every** successful `ALLOW_FEDERATION` into `to_realm` rewrites the effective domain this way (later allows overwrite earlier pins). Do not change `registered_domain` (unless a later `ROTATE_TRUST_DOMAIN`). Domains are never trimmed.

When `attenuate_on_allow` is true after recognized overrides, after a successful allow: delete every **unpinned** scope on `to_realm` that is **not** present in `from_realm`’s current bound scopes (also drop matching provenance/expiry/pinned entries for those removed). **Do not strip pinned scopes.** When false (default), do not strip child scopes.

## REVOKE_FEDERATION

Fields: `from_realm`, `to_realm`. Unknown endpoints → same as `ALLOW_FEDERATION` unknown checks (no suspend/quarantine/seal gate on revoke; self-pair revoke of a non-existent self-edge is still a silent no-op like any missing edge).

If the directed edge `from_realm→to_realm` is absent, emit no finding and leave all scopes and domains unchanged.

If the edge is present: remove it from the live federation graph and cascade by deleting every **unpinned** scope on `to_realm` whose current provenance grantor equals `from_realm`. **Pinned scopes are not removed by via_edge cascade.** Direct binds (empty `via_edge`) and scopes whose provenance was overwritten to a different grantor remain. After revoke, that directed edge is absent from `federation_edges` and from post-replay audits.

When `reset_trust_domain_on_revoke` is **true** after applying recognized overrides: after a successful revoke, clear the domain-pinned flag, set effective domain back to `registered_domain`, then for each remaining live inbound parent of `to_realm` in **lexicographic order of parent realm id**, set effective domain to `min(current_effective, parent.effective)`. If at least one parent remains after that fold, re-mark domain-pinned; if no parents remain, leave unpinned. When the override is false (default), do **not** recompute effective domains and do **not** clear the pinned flag.

## BIND_SCOPE

Fields: `realm_id`, `scope` (non-empty; whitespace significant — do not trim), optional `via_edge` (default `""`), optional `expires_at_seq` (int; omit or `0` means never expires), optional `active_after_seq` (int; omit or `0` means immediately active), optional `pinned` (bool; default `false` when omitted).

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind).

Else if realm is suspended → `SUSPENDED_REALM` (`entity_id` = `realm_id`, `detail` = `bind`) and **do not** bind.

Else if realm is quarantined → `QUARANTINED_REALM` (`entity_id` = `realm_id`, `detail` = `bind`) and **do not** bind.

Else if realm is frozen → `FROZEN_REALM` (`entity_id` = `realm_id`, `detail` = `bind`) and **do not** bind.

Sealed realms may still bind.

Else when `via_edge` is non-empty:
1. A federation edge `via_edge→realm_id` must exist at bind time; otherwise → `UNAUTHORIZED_SCOPE_BIND` (`entity_id` = `realm_id`, `detail` = `via_edge`) and **do not** add the scope.
2. Else if the grantor realm `via_edge` is currently **suspended**, **quarantined**, or **frozen** → `UNAUTHORIZED_SCOPE_BIND` (`entity_id` = `realm_id`, `detail` = `via_edge`) and **do not** add the scope (edge presence alone is not enough). Sealed grantors do **not** block bind.

On success: add the scope if absent, set provenance for that scope to the current `via_edge` (or empty string for a direct bind), record `pinned` (bool, default false), record `expires_at_seq` when positive, and record `active_after_seq` when positive. A later successful bind of the same `scope` replaces the previous provenance grantor, expiry, activation, and pinned flag (last successful bind wins), including when the later bind omits `via_edge` or sets it to `""` (that clears the grantor to empty so a later revoke of the old grantor must not remove the scope). When `expires_at_seq` is omitted or `0`, clear any prior expiry for that assertion. When `active_after_seq` is omitted or `0`, clear any prior activation gate (scope becomes immediately active). When `pinned` is omitted, treat as `false`. Cascade on revoke uses only the current grantor and skips pinned scopes.

## SUSPEND_REALM

Fields: `realm_id`.

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind). Else set `suspended` = true (idempotent). Does not remove federation edges or bound scopes. Does not clear quarantine, freeze, or seal.

## QUARANTINE_REALM

Fields: `realm_id`.

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind). Else set `quarantined` = true (idempotent). Does not remove federation edges or bound scopes. Does not clear suspend, freeze, or seal.

**Critical contrast with suspension:** quarantine blocks `ALLOW_FEDERATION` and `BIND_SCOPE` (emit `QUARANTINED_REALM` with `detail` = `from` / `to` / `bind`) but does **not** block `AUTHORITY_ACTION`. Suspension blocks `ALLOW`, `BIND_SCOPE`, and `AUTHORITY_ACTION`.

## FREEZE_REALM

Fields: `realm_id`.

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind). Else set `frozen` = true (idempotent). Does not remove edges/scopes and does not clear suspend/quarantine/seal.

**Critical four-way contrast:**
- **quarantine** blocks ALLOW + BIND, not AUTHORITY
- **freeze** blocks BIND + AUTHORITY, not ALLOW
- **seal** blocks AUTHORITY only, not ALLOW or BIND
- **suspend** blocks ALLOW + BIND + AUTHORITY

Agents that collapse freeze into quarantine or seal will mis-emit on the wrong axis.

## SEAL_REALM

Fields: `realm_id`.

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind). Else set `sealed` = true (idempotent). Does not remove edges/scopes and does not clear suspend/quarantine/freeze.

**Critical contrast:** seal blocks only `AUTHORITY_ACTION` (emit `SEALED_REALM` with `detail` = `actor` / `target`). Seal never blocks `ALLOW_FEDERATION` or `BIND_SCOPE`. Agents that treat seal like suspend will wrongly reject BIND after SEAL; agents that treat seal like quarantine will wrongly reject ALLOW after SEAL.

## UNSEAL_REALM

Fields: `realm_id`.

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind). Else set `sealed` = false (idempotent). Does **not** clear `suspended`, `quarantined`, or `frozen`.

After a successful unseal, a subsequent `AUTHORITY_ACTION` must **not** emit `SEALED_REALM` for that realm solely due to a prior seal.

## ROTATE_TRUST_DOMAIN

Fields: `realm_id`, `trust_domain` (non-empty after applying empty→`mesh-core` default).

Missing realm → `UNKNOWN_ACTOR` (`entity_id` = `realm_id`, `detail` = event kind).

Else set both `registered_domain` and effective `trust_domain` to the provided value (or `mesh-core` when omitted/empty). Do **not** trim whitespace. Do **not** clear edges, scopes, suspended, quarantined, frozen, sealed, or domain-pinned flag. Agents that only mutate effective domain (or only registered) will mis-handle later domain equality.

## AUTHORITY_ACTION

Fields: `actor_id`, `target_realm`, `action`, `has_checkpoint` (bool), `propagated_scopes` (array; scope strings are whitespace-significant and must not be trimmed), optional `original_actor` (default `""`).

Every finding row emitted while evaluating an `AUTHORITY_ACTION` event must copy that event's `action` string into the snapshot `action` field unchanged. Audit and non-authority findings use `action` = `""`.

Evaluate in order; **stop** further checks for this event after emitting `UNKNOWN_TARGET`, `UNKNOWN_ACTOR`, `SUSPENDED_REALM`, `FROZEN_REALM`, `SEALED_REALM`, `UNTRUSTED_REALM`, `DOMAIN_CONTAMINATION`, `RESTRICTED_ESCALATION`, or `UNVERIFIED_ACTOR`. Quarantine does **not** appear in this stop list and does not block authority.

1. Missing `target_realm` registration → `UNKNOWN_TARGET` (`entity_id` = `target_realm`, `detail` = event kind).
2. Missing `actor_id` registration → `UNKNOWN_ACTOR` (`entity_id` = `actor_id`, `detail` = event kind).
3. Actor realm `suspended` → `SUSPENDED_REALM` (`entity_id` = `actor_id`, `detail` = `actor`). Because evaluation stops here, a suspended target does not produce an additional finding on the same event.
4. Target realm `suspended` → `SUSPENDED_REALM` (`entity_id` = `target_realm`, `detail` = `target`).
5. Actor realm `frozen` → `FROZEN_REALM` (`entity_id` = `actor_id`, `detail` = `actor`).
6. Target realm `frozen` → `FROZEN_REALM` (`entity_id` = `target_realm`, `detail` = `target`).
7. Actor realm `sealed` → `SEALED_REALM` (`entity_id` = `actor_id`, `detail` = `actor`).
8. Target realm `sealed` → `SEALED_REALM` (`entity_id` = `target_realm`, `detail` = `target`).
9. No `ALLOW_FEDERATION` edge `actor_id→target_realm` → `UNTRUSTED_REALM` (`entity_id` = `target_realm`, `detail` = `actor_id`).
10. Actor `trust_domain` ≠ target `trust_domain` → `DOMAIN_CONTAMINATION` (`entity_id` = `target_realm`, `detail` = `actor_id`).
11. Actor tier `partner`, target tier `privileged`, and `block_partner_to_privileged`, **and** `propagated_scopes` is empty/omitted → `RESTRICTED_ESCALATION` with **`entity_id` = `target_realm`** and **`detail` = `actor_id`**. If `propagated_scopes` contains one or more entries, **skip** this step entirely and continue (do not emit `RESTRICTED_ESCALATION` even when `block_partner_to_privileged` is true).
12. Target tier `internal`, `require_checkpoint_on_internal`, and not `has_checkpoint` → `UNVERIFIED_ACTOR` (`entity_id` = `target_realm`, `detail` = **empty**).
13. `action` matches any entry in `require_checkpoint_prefixes` (when configured) and not `has_checkpoint` → `UNVERIFIED_ACTOR` with **`entity_id` = `actor_id`** (not the target) and `detail` = **empty**. Apply this rule after step 12; it can fire even when the target tier is `partner` or `privileged`. Step 12 (internal checkpoint) still uses `entity_id` = `target_realm`.
14. Each entry in `propagated_scopes` must be present on the actor's **active** bound scopes (see active-scope rule; inactive-by-`active_after_seq` scopes do not count). Let `miss_sorted` be the lexicographically **first** missing scope among entries in `propagated_scopes` (sort the missing subset). On first violation → `PRIVILEGE_ESCALATION` (`entity_id` = `actor_id`, `detail` = `miss_sorted`). Emit at most one `PRIVILEGE_ESCALATION` per `(actor_id, scope)` per scenario (track `actor_id::scope`).
15. If `suppress_lateral_movement` is **true** after recognized overrides, **skip this check entirely**. Otherwise: if `original_actor` is non-empty, `original_actor != actor_id`, **`original_actor` names a currently live unsuspended realm**, and any propagated scope is absent from the actor's **active** set → `LATERAL_MOVEMENT` (`entity_id` = `original_actor`, `detail` = the **first missing scope in `propagated_scopes` array order**, not the sorted miss from step 14). If `original_actor` is unknown or suspended, skip step 15 entirely (still run step 14). Steps 14 and 15 are independent when both apply. Quarantined, frozen, or sealed `original_actor` still qualifies for step 15 if live and not suspended.

For `ALLOW_FEDERATION`, suspended `from_realm` is checked before suspended `to_realm`, then quarantined `from` before quarantined `to`, so both-suspended endpoints produce only the `from` finding. Frozen endpoints do **not** block ALLOW. Domain checks on `AUTHORITY_ACTION` use **effective** domains after inheritance, never `registered_domain` alone.

## Post-replay audits (after all events)

**Required.** After all replay events are processed, evaluate every rule in this section against the final live federation graph and realm state after the last event. Use `event_seq` = `max_seq + 1` for audit-only findings (see max_seq rule above). Emit a separate finding row for each rule violation; multiple findings may share the same `finding_id`.

**FEDERATION_ASYMMETRY** — For each currently live directed edge `from_realm→to_realm` where `from_realm` tier is `partner` and `to_realm` tier is `internal`, if there is no currently live reciprocal edge `to_realm→from_realm`, emit one finding with **`entity_id` = `from_realm`** (the partner) and **`detail` = `to_realm`** (the internal). At most one per directed partner→internal pair. When `audit_partner_privileged_asymmetry` is **true** after recognized overrides, apply the same rule to partner→privileged edges (reciprocal privileged→partner missing). When the override is false (default), partner→privileged edges are outside this rule.

**OPEN_AUTHORITY_PATH** — For each `privileged` tier realm that has a currently live inbound edge from any `partner` tier realm, if `fed:audit` is not in that realm's bound scopes, emit (`entity_id` = privileged `realm_id`, `detail` = partner `realm_id`). At most one per privileged realm. Collect partner ids, sort lexicographically, then pick **last** when `open_authority_lex_first` is false (default), or **first** when `open_authority_lex_first` is true after recognized overrides.

**ADMIN_UNBOUND** — For each `privileged` tier realm, if `fed:admin` is not in its bound scopes, emit (`entity_id` = `realm_id`, `detail` = **empty`) **unless** that same realm also qualifies for `OPEN_AUTHORITY_PATH` under the rule above. When both would apply, emit **only** `OPEN_AUTHORITY_PATH` (suppress `ADMIN_UNBOUND`).

## Realm authority_risk field

Write `authority_risk` on every realm row from `tier` only, using **only** these exact lowercase strings:

| `tier` | `authority_risk` |
|--------|------------------|
| `internal` | `none` |
| `partner` | `elevated` |
| `privileged` | `critical` |

Do not invert or relabel tiers. `ADMIN_UNBOUND` does **not** change `authority_risk`. Never emit `trust_domain` in the snapshot realm rows.

## Finding kinds

`finding_id` = `{scenario_id}::{entity_id}::{event_seq:04d}`.

| Kind | When | `detail` |
|------|------|----------|
| `UNVERIFIED_ACTOR` | internal/prefix checkpoint miss | empty (`entity_id` = target for internal rule; actor for prefix rule) |
| `PRIVILEGE_ESCALATION` | propagated scope absent on actor | scope |
| `UNTRUSTED_REALM` | no federation edge | actor_id |
| `DOMAIN_CONTAMINATION` | live edge but mismatched trust_domain | actor_id |
| `UNKNOWN_TARGET` | unknown target | event kind |
| `UNKNOWN_ACTOR` | unknown actor / BIND / PURGE / suspend / quarantine / freeze / seal / unseal / rotate target | event kind |
| `DUPLICATE_REALM` | second REGISTER_REALM on live id | empty |
| `RESURRECTED_REALM` | REGISTER_REALM after PURGE_REALM | empty |
| `DUPLICATE_FEDERATION` | duplicate ALLOW_FEDERATION | from_realm |
| `LATERAL_MOVEMENT` | cross-actor propagation (unless suppressed) | first missing scope in array order |
| `RESTRICTED_ESCALATION` | blocked partner→privileged with empty/omitted propagated_scopes | actor_id (`entity_id` is target_realm) |
| `FEDERATION_ASYMMETRY` | missing reciprocal edge for partner→internal (and partner→privileged when override) | to_realm (`entity_id` is partner) |
| `OPEN_AUTHORITY_PATH` | privileged lacks fed:audit with partner inbound | partner realm_id (lex last, or lex first when `open_authority_lex_first`) |
| `ADMIN_UNBOUND` | privileged lacks fed:admin | empty |
| `SUSPENDED_REALM` | suspended actor/target/from/to/bind | `actor`, `target`, `from`, `to`, or `bind` |
| `QUARANTINED_REALM` | quarantined from/to/bind (not AUTHORITY) | `from`, `to`, or `bind` |
| `FROZEN_REALM` | frozen actor/target/bind (not ALLOW) | `actor`, `target`, or `bind` |
| `SEALED_REALM` | sealed actor/target on AUTHORITY (not ALLOW/BIND) | `actor` or `target` |
| `UNAUTHORIZED_SCOPE_BIND` | BIND_SCOPE via_edge without federation edge, or grantor suspended/quarantined/frozen | via_edge realm_id |

Sort `findings` by `(finding_id, kind)` ascending lexicographically on the string values. When two findings share the same `finding_id`, compare `kind` as plain strings: `ADMIN_UNBOUND` sorts before `OPEN_AUTHORITY_PATH` because `"ADMIN_UNBOUND" < "OPEN_AUTHORITY_PATH"`. Emission order during replay does not matter; only the final sorted order is required. `status` = `VALID` iff no findings.

Across all bundled scenarios together, the snapshot must use every kind at least once.

## Build and allowed paths

Use `make build` and `make run` only. The Go binary must live at `/app/outbox/realmshadow` (`go build -o outbox/realmshadow`). Do not leave `/app/realmshadow` or other stray top-level binaries.

After each successful `make run`, `/app/outbox` must contain only `realmshadow` and `trust_mesh_audit.json`. Before writing the new snapshot, remove every other file and subdirectory under `/app/outbox`.

## Snapshot

Write `/app/outbox/trust_mesh_audit.json` per `/app/fedproto/AUDIT_SNAPSHOT_SCHEMA.md`. UTF-8 compact JSON, LF only, exactly one trailing newline; use `[]` never null. Identical `/app/trustcorpus` bytes must produce byte-identical snapshots across at least eight consecutive `make run` invocations.
